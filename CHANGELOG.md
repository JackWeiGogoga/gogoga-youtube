# Changelog

All notable changes to gogoga YouTube are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/). 中文版见 [CHANGELOG.zh-CN.md](CHANGELOG.zh-CN.md).

## [0.3.0] - 2026-10-15

### Added
- English and Simplified Chinese interface, following Obsidian's language.
- English README with a Simplified Chinese translation.

## [0.2.1] - 2026-10-14

### Changed
- Reworded the plugin description.

## [0.2.0] - 2026-10-14

First public release.

### Added
- Add one channel or paste many: channel URLs, `@handles`, `UC…` IDs and Google Takeout `subscriptions.csv`.
- Channels can belong to several groups; one Markdown note per channel and a generated `Channels.base` table/card view.
- Fetches recent uploads from public feeds; filter by group, search or unread, mark as read, and save chosen videos as notes.
- Refresh at startup, on an interval or manually; pause individual channels.
- Optional Google account sync (read-only scope) that imports and keeps mirroring your subscriptions.
